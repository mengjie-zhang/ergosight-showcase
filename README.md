# ErgoSight

ErgoSight turns ordinary video of real work into a full 3D picture of how every worker moves, and scores each
posture for ergonomic risk (RULA / REBA), body part by body part and moment by moment.

**Open the page:** https://mengjie-zhang.github.io/ergosight-showcase/

This repository holds only the showcase page (`index.html` and `media/`). It has no build step; you can also download
the repository and open `index.html` directly.

Footage: the demo clips are screen recordings of the ErgoSight app; the site footage comes from free stock libraries
(Pexels / Pixabay). `media/gaze-teamwork-1.mp4` is an iStock preview clip.
